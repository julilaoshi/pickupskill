# Use Cases

## Downloads Folder

Best for:

- screenshots
- PDFs
- exported media
- temporary references
- mixed documents

Default behavior:

- scan loose files
- group obvious file pairs
- move ambiguous documents to review
- keep folder depth shallow

## Creator Workspace

Best for:

- thumbnails
- video exports
- subtitles
- draft scripts
- reference images

Default behavior:

- keep media files and captions together
- preserve export names
- keep draft scripts visible
- avoid splitting asset packages

## Design Asset Folder

Best for:

- source design files
- preview images
- logo files
- moodboard references

Default behavior:

- keep source and preview together
- separate reusable references from active design packages
- move uncertain images into review buckets

## Research Or Writing Folder

Best for:

- drafts
- PDFs
- notes
- reference folders

Default behavior:

- keep draft and source folders together when clearly related
- do not rename citations or paper files aggressively
- move ambiguous PDFs to review

## Software Project Folder

Best for:

- identifying what not to move

Default behavior:

- detect project and runtime signals
- list risks
- avoid moving dependencies
- ask before restructuring
