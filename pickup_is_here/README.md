# pickup_is_here / 整理结果在这里

This folder is the default result zone for the public `v1.0` package.
这个文件夹是 public `v1.0` 默认给用户放整理方案和整理结果的地方。

Use it for / 适合放：

- your cleanup plans
- your completed organization notes
- your own public-safe local assets that belong to your derivative work

Do **not** use this folder for / 不要放：

- private absolute-path workflow traces
- private workspace maps
- sensitive documents
- files copied from someone else's computer
- dependency folders that should remain in their original project

## Start Here / 从这里开始

If you are not sure where to click first:
如果你不知道先点哪里：

1. open `OPEN_HOME.html`
2. check `cleanup_plans/`
3. check `organized_results/`
4. read this file if you forget the boundary

## Folder Meaning / 文件夹含义

- `cleanup_plans/`
  - plans written before moving files
- `organized_results/`
  - notes written after cleanup
- `assets/`
  - your own public-safe derivative assets

## Boundary / 边界

- `references/` = method and safety zone
- `pickup_is_here/` = your result zone
- `site/index.html` = public showcase shell
